Computer networking is the process of connecting computers and devices so they can communicate and share data and resources. A network can use wired technologies such as Ethernet or wireless technologies such as Wi-Fi. Common networking concepts include IP addresses, routers, switches, DNS, TCP/IP, HTTP, and network security. Routers forward packets between different networks, while switches connect devices within the same local network. Reliable communication depends on protocols that define how data is transmitted, received, and processed. Networking is widely used in web applications, cloud computing, distributed systems, and modern enterprise infrastructure.
